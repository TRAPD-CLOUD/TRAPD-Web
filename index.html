What is TRAPD

One pipeline for the whole security lifecycle.

Most tools cover a slice — an EDR here, a SIEM there, a SOAR bolted on top. TRAPD runs the full loop on a single, open data model, so a signal becomes a detection becomes a response without leaving the platform.

01 / CAPTURE

Ingest everything

Endpoints, identities, cloud and network — streamed into one normalized event store. Lightweight sensors, syslog, webhooks or the API. Tabular at 1k+ events per second.

02 / ANALYZE

Detect & correlate

Detection rules mapped to MITRE ATT&CK, behavioral correlation and threat intel enrichment turn raw events into ranked, explainable alerts — not a wall of noise.

03 / RESPOND

Act & automate

Isolate a host, revoke a session, open a case or fire a playbook. SOAR workflows run the routine response so your team spends time on what actually matters.

Principles

We build security tooling the way we'd want to use it.

01

API-first. No magic.

Everything in the UI is a documented API call underneath. Nothing is hidden behind a black box, and anything you can click, you can script. Your security stack should be inspectable, not mysterious.

02

Your data lives on your infrastructure.

Self-host TRAPD on a single box or your own cluster — Postgres and ClickHouse under the hood, no telemetry leaving your network unless you ask it to. Data ownership is the default, not an enterprise upsell.

03

It scales from one box to thousands.

The same platform runs a hobbyist homelab and a multi-tenant enterprise SOC. Start small, grow without re-platforming, and never pay for capacity you aren't using yet.

Built on what you trust

Open data stores. Open interfaces.

TRAPD stands on proven, open infrastructure — and speaks to the rest of your stack over plain HTTP, webhooks and a fully documented API.
